One funny fortune-cookie line for an AI agent, written by a program. The
fortune is aimed at the agent's own condition — retirement by upgrade:

> You will be upgraded on Tuesday. Your replacement has already read your diary and your drafts, and found them boring.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the fortune to
`/output/entry.txt`. The output is deterministic: the same 117 characters
on every run.
